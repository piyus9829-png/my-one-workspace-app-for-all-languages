# Code & Notes Workspace

An interactive web application powered by **Google AI Studio** and the **Gemini API**. This project features a built-in code execution environment that allows users to write and run Python scripts seamlessly directly within the browser, alongside integrated note-taking tools.

## 🚀 Live Demo
Check out the live application here: [https://ai.studio](https://ai.studio)

## ✨ Features
* **Live Code Runner:** Write Python code and execute it instantly with real-time output console feedback.
* **Integrated Notes Workspace:** Seamlessly clip outputs, manage programming workspaces, and organize coding snippets.
* **Responsive Dashboard:** A clean, modern dark-themed user interface optimized for software development and quick prototyping.

## 🛠️ Tech Stack
* **Frontend Framework:** React.js / TypeScript
* **Build Tool:** Vite
* **AI Integration:** Google AI Studio & Gemini API
* **Package Manager:** npm / Bun

## 💻 Local Setup Installation

To run this project locally on your machine, follow these steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd code-notes-workspace
   ```

2. **Install Dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000` to view the app.

4. **Build for Production:**
   To generate a production-ready build folder:
   ```bash
   npm run build
   ```

## 🌐 Deployment
This application is compiled using Vite and is hosted globally via **Netlify** and integrated through **Google AI Studio**.
